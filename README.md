# kaleidoscope

Quilt blocks, repeats, plaids and pixel fields from a seed. Pick a look, shuffle the form, recolour, and export PNG or SVG. The whole pattern lives in the link, so any look can be shared.

- **Looks**: starting points after Waybill's swatches, the WillB card, pixel posters, Duluth wrappers, Amsterdam signs and a scrap quilt
- **Compose**: bricks, strips and striped modules with circles and domes, after the Duluth wrappers
- **Pattern**: library blocks or generated ones (size, symmetry, fill, triangles, halves, circles, stripes), plaids (plain, twill, over, under), fields (camo, patches, streaks), cut to a circle, arch or diamond
- **Layout**: grid, mirror, twist, pinwheel, half drop, brick, step, lattice; sashing and posts; colourways
- **Colour**: fixed sets or generated palettes in OKLCH; mixed palettes per tile

Space shuffles, C recolours, Cmd+Z undoes.
