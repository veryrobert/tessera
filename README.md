# tessera

Quilt blocks on a grid, in random colours, after Waybill's swatches and the scrap quilt. Shuffle the form, recolour, pinch or drag to change how many blocks fit, and export PNG or SVG. The whole pattern lives in the link, so any look can be shared.

- **Pattern**: the block, blocks across, repeat (grid, mirror, twist, pinwheel, half drop, brick, step, lattice), swap alternate, gap with its colour and corner squares, format
- **Colour**: random colours or a set, mix (how many blocks get their own colours), colour amount down to black and white
- **Looks**: starting points
- **Export**: PNG 2K or 4K, SVG, copy link

Space shuffles, C recolours, Cmd+Z undoes. Pinch, drag up or down, or scroll to change the blocks across.
